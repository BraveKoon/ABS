# ABS 로봇 심판 v0.1.2

카메라로 탁구공을 추적해 야구 ABS(자동 볼·스트라이크 판정)처럼 스트라이크 / 볼을 판정하는 웹 앱입니다.
서버 없이 브라우저에서 동작하며, 영상은 밖으로 전송되지 않습니다.

## 바로 사용하기

GitHub Pages: https://bravekoon.github.io/ABS/

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 단일 HTML 앱 |
| `worker.js` | 같은 HTML을 응답하는 Cloudflare Worker (단일 파일) |
| `wrangler.toml` | wrangler 배포 설정 |

## 사용법

1. https 주소(또는 localhost)에서 열고 **카메라 시작**을 누른 뒤 카메라를 허용합니다. 카메라는 https에서만 켜집니다.
2. **🎨 공 색 찍기**를 누르고 화면 속 공을 여러 번 탭합니다. 기본값은 주황 탁구공입니다.
3. **🎯 존 조정**에서 주황 박스를 끌어 이동하고, 점을 끌어 크기를 바꾸고, 박스 밖을 끌어 새로 그립니다.
4. 공을 카메라 쪽으로 던지면 판정 크기에 닿는 순간의 위치로 판정합니다. 존에 조금이라도 걸치면 스트라이크입니다.

**✂️ 크롭**으로 남길 영역을 정하고 [적용]하면 그 부분만 확대해서 추적합니다. 공이 멀리서 작게 보일 때 정확해지며, [전체 화면]으로 되돌립니다.
볼 / 스트라이크 / 아웃은 카운트 패널의 ＋/−로 수동 조정할 수 있습니다.

촬영한 영상은 **영상 불러오기**로 분석할 수 있습니다.

## Cloudflare 배포

대시보드: Workers & Pages → Create → Worker → Edit code에 `worker.js`를 붙여넣고 Deploy.

CLI:

```
npx wrangler deploy
```

## 한계

- 조명이 어둡거나 배경에 같은 색이 있으면 오인식할 수 있습니다. 마스크 보기로 확인하며 색 범위를 조정하세요.
